# 皮肤图片不透明度设计

## 目标

将当前几乎不可见的“面板不透明度”控制替换为“图片不透明度”，使主聊天窗口与外观设置预览都能像 IDEA/PyCharm 一样独立调节背景图片透明度。

## 已确认行为

- 设置页只保留一个相关滑块，名称改为“图片不透明度”。
- 范围为 `0%` 至 `100%`：`0%` 隐藏图片，`100%` 显示原图。
- “遮罩强度”继续独立控制图片上方的浅色或深色可读性遮罩。
- 仅影响主聊天窗口的沉浸皮肤；设置窗口继续只提供实时预览。
- 不恢复侧边栏和输入框的面板底色，输入框继续透明。

## 兼容策略

现有持久化与前后端协议字段 `panel_opacity_percent` 保持不变，避免升级后无法读取已保存配置；应用内部将其作为兼容字段承载图片不透明度。新范围从 `55..=100` 调整为 `0..=100`，已有值可自然迁移。

## 渲染设计

主聊天窗口使用独立固定伪元素绘制背景图片，并在该图片层应用透明度与模糊。页面基色与可读性遮罩保留在图片层下方/上方，因此调低图片透明度不会同时淡化页面内容或遮罩。外观设置预览同样只对背景图片节点设置透明度，预览卡片保持固定可读样式。

## 验证

- TypeScript reducer 覆盖 `0..100` 边界与兼容字段序列化。
- 外观设置 DOM 测试覆盖滑块标签、范围及实时图片透明度。
- Rust store 测试覆盖新范围。
- Rust adapter 可执行脚本测试覆盖图片透明度进入独立背景层，且不再改变 DSH 面板变量。
- 运行完整前端测试、Rust 测试、类型检查与构建。
