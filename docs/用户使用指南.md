# DSH Desktop 中文使用指南

DSH Desktop 是 DeepSeek Harness（DSH）的 Windows 桌面外壳。它把官方 WebUI、
DSH 运行时下载、版本兼容检查、系统托盘和自定义背景整合到一个独立窗口中，首次使用
不需要手动下载 DSH 源码，也不需要自己打开终端启动服务。

> 当前版本面向个人和小范围测试，支持 Windows 10/11 x64，仅按当前用户安装。

## 1. 下载与安装

1. 打开项目的 [Releases](https://github.com/ccx-dym/dsh-gui/releases) 页面。
2. 进入最新的 `desktop-v...` 版本，下载文件名形如
   `DSH-Desktop_<版本>_x64-setup.exe` 的安装包。
3. 双击安装。程序安装到当前 Windows 用户，不需要管理员权限。
4. 安装完成后，从开始菜单打开 **DSH Desktop**。

安装包只包含桌面客户端和必要的启动资源，因此体积较小。Microsoft Edge WebView2
Runtime 缺失时，安装器会使用微软的在线安装程序补齐它。

## 2. 首次安装 DSH

首次启动时，桌面端会读取 DSH 官方版本和本项目的签名兼容清单：

1. 在“DSH 运行时更新”区域点击“检查兼容版本”或“重新检查”。
2. 出现“安装 DSH 0.1.1-rc.2”后，确认下载。
3. 客户端会依次完成下载、文件大小和 SHA-256 校验、签名验证与隔离探活。
4. 按界面提示确认在下次冷启动激活，然后退出并重新打开 DSH Desktop。
5. 探活成功后，主窗口自动进入 DeepSeek Harness 官方 WebUI。

运行时压缩包约 103 MiB，解压后会更大。下载过程中不要强制结束安装流程；如果网络
中断，可以重新检查，旧版本和本地数据不会被替换。整个过程不需要 DSH 源码。

## 3. DSH 与桌面客户端如何更新

两条更新通道相互独立：

- **DSH 更新**：桌面端扫描 DeepSeek Harness 的官方 npm 版本；只有经过本项目兼容
  验证并写入签名清单的版本才允许安装。
- **桌面客户端更新**：用于更新窗口、托盘、兼容逻辑和皮肤功能，不会删除 DSH 或
  DSH 数据。

当官方 DSH 发布新版本时，客户端会提示“官方版本已发布”。如果当前桌面端已经兼容，
随后会开放 DSH 安装；如果还不兼容，会提示先更新桌面客户端。也可以在更新区域手动
点击“再次检查”。

## 4. 系统托盘

- 关闭主窗口时，程序隐藏到系统托盘，DSH 不会因此退出。
- 单击托盘图标可恢复主窗口。
- 托盘菜单可恢复/隐藏窗口、打开皮肤设置、重启 DSH 或完整退出。
- 需要彻底结束 DSH 时，请使用托盘菜单中的“退出”，不要只关闭窗口。

## 5. 使用自己的图片作为皮肤

1. 在托盘菜单中选择“选择或设置皮肤”。
2. 选择 PNG、JPEG 或 WebP 图片。源图片会复制到应用管理目录，之后移动原图不会影响
   已保存的皮肤。
3. 调整填充方式、位置、模糊、遮罩和面板透明度。
4. 开启“沉浸模式”可让背景连续覆盖主聊天窗口的自绘标题栏、左侧栏和对话区。
5. 保存设置；需要撤销时选择“恢复默认”。

启用沉浸式皮肤后，对话输入卡片会透出背景。外观设置和更新窗口仍使用 Windows 原生
标题栏；弹窗、菜单和确认界面会保留按“面板透明度”计算的底色，以保证内容可读。

皮肤适配按 DSH 版本进行兼容保护。如果新版 DSH 的页面结构还没有验证，桌面端会自动
关闭自定义皮肤并恢复官方界面，不影响 DSH 的核心功能。

## 6. 数据目录

程序预定义了安全的独立目录，目前不能在界面中改为任意路径：

| 内容 | 默认位置 |
| --- | --- |
| 桌面程序 | `%LOCALAPPDATA%\DSH Desktop` |
| DSH 运行时、下载缓存、皮肤和 WebView 数据 | `%LOCALAPPDATA%\DSH Desktop Data` |
| DSH 会话/配置、桌面设置和诊断日志 | `%APPDATA%\DSH Desktop` |

这样可以避免覆盖全局 DSH、`~/.dsh` 或其他工作区。默认卸载会移除桌面程序，但为避免
误删个人内容，独立数据目录可能保留；重装后可以继续复用。若要彻底清理，请先在托盘
中完整退出程序，再自行备份并删除上表后两个目录。

## 7. 常见问题

### 显示“暂时无法读取发布通道”或“当前处于离线状态”

先点击“重新检查”。客户端支持读取当前用户的 Windows 显式代理设置；仍失败时，请
确认 GitHub Raw、GitHub Releases 和 npm registry 可以访问，然后重启客户端。

### 显示“官方版本已发布”，但没有安装按钮

这表示官方版本已被发现，但兼容构建还未发布，或该版本需要更新的桌面客户端。继续使用
当前 DSH 即可，不要绕过兼容检查手工覆盖受管运行时。

### 主窗口关闭后程序仍在运行

这是系统托盘模式的正常行为。请从托盘恢复窗口或选择“退出”。

### 去哪里查看诊断日志

日志位于 `%APPDATA%\DSH Desktop\logs`。反馈问题时可以提供相关的
`diagnostics-*.jsonl`，但不要附带模型 API Key、聊天内容或其他敏感文件。

### 安装包或项目目录为什么很大

正式安装包只有数 MiB。源码目录在构建后变大，主要来自可重建的 Rust `target`、前端
`node_modules` 和 runtime 构建输出；它们不是需要分发的安装包。日常使用只需下载
Release 里的 `setup.exe`。
